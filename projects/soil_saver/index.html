El Proyecto The Project

Una brecha en los datos que limita lo que podemos aprender

A data gap that limits what we can learn

La detección de erosión mediante métodos de deep learning ha mostrado resultados prometedores, pero la ausencia de datos públicos dificulta reproducirlos o mejorarlos: de 113 artículos revisados, solo 2 comparten datos accesibles, y ambos cubren una única región y un único sensor.

SoilSaveR es un intento de cerrar esa brecha, proponiendo una metodología para generar un dataset público y de acceso abierto. En lugar de depender de un único sensor o ubicación, combina múltiples fuentes, abarca regiones diversas y ofrece etiquetas explícitas que indican dónde ocurre la erosión.

En resumen, SoilSaveR propone generar un dataset etiquetado, público, multimodal, multi-región para la detección de erosión a partir de imágenes satelitales.

Esta metodología utiliza primero fórmulas matemáticas fijas basadas en la física y la geografía (RUSLE + índices topográficos del DEM) para acotar automáticamente las zonas con alto riesgo de erosión, y luego una verificación visual humana sobre imágenes satelitales Sentinel-2, para asegurar que cada etiqueta tenga sentido físico y esté confirmada visualmente.

The detection of erosion via deep learning methods has shown promising results, but the absence of public data makes them difficult to reproduce or improve: of 113 papers reviewed, only 2 share accessible data, and both cover a single region and a single sensor.

SoilSaveR is an attempt to close that gap by proposing a methodology to generate a public, open-access dataset. Instead of relying on a single sensor or location, it combines multiple sources, covers diverse regions, and provides explicit labels showing where erosion occurs.

In short, SoilSaveR proposes to generate a labeled, public, multi-modal, multi-region dataset for erosion detection from satellite imagery.

This methodology first uses fixed mathematical formulas grounded in physics and geography (RUSLE + DEM topographic indices) to automatically narrow down high-risk erosion zones, followed by human visual verification on Sentinel-2 satellite imagery to ensure each label makes physical sense and is visually proven.

How scientists build the dataset

Pipeline híbrido multimodal

Multimodal Hybrid Pipeline

  • ▸ Modelado determinista (RUSLE + DEM) calcula susceptibilidad a la erosión y genera una máscara de zonas candidatas.
  • ▸ Deterministic modeling (RUSLE + DEM) computes erosion susceptibility and generates a candidate-zone mask.
  • ▸ Índices topográficos (TWI, SPI, slope-area) refinan las zonas candidatas con criterios físicamente fundamentados.
  • ▸ Topographic indices (TWI, SPI, slope-area) refine candidate zones using physically grounded criteria.
  • ▸ La anotación humana guiada confirma la presencia real de erosión solo dentro de las zonas candidatas, con una reducción del esfuerzo del 50–80%.
  • ▸ Guided human annotation confirms actual erosion presence only within candidate zones, achieving a 50–80% effort reduction.
  • ▸ Los objetivos de etiquetado abarcan cárcavas >10 m y zonas de erosión laminar en múltiples regiones.
  • ▸ Labeling targets cover gullies >10 m and sheet erosion zones across multiple regions.
  • ▸ La publicación abierta incluye el protocolo de etiquetado, las métricas de acuerdo entre anotadores y las herramientas, todo liberado públicamente.
  • ▸ Open release includes the labeling protocol, inter-annotator agreement metrics, and tools, all released publicly.

Parte del stack de datos y modelos

Some of the Data & Model Stack

  • ▸ Sentinel-2 (10 m óptico) sirve como base del etiquetado visual, con imágenes multiespectrales de alta resolución.
  • ▸ Sentinel-2 (10 m optical) serves as the visual labeling base using high-resolution multispectral imagery.
  • ▸ ALOS PALSAR DEM (12,5 m) aporta el modelo digital de elevación para RUSLE y el cálculo de índices topográficos.
  • ▸ ALOS PALSAR DEM (12.5 m) provides the digital elevation model for RUSLE and topographic index computation.
  • ▸ Sentinel-1 SAR (10 m, opcional) añade una modalidad de radar para enriquecer el dataset multimodal.
  • ▸ Sentinel-1 SAR (10 m, optional) adds a radar modality to enrich the multi-modal dataset.
  • ▸ Google Earth Engine se encarga del acceso y el procesamiento en la nube de todos los datos satelitales.
  • ▸ Google Earth Engine handles cloud-based access and processing for all satellite data.
  • ▸ Las arquitecturas objetivo incluyen DeepLabV3+, U-Net y SAM, modelos de segmentación que este dataset permite entrenar de forma reproducible por primera vez.
  • ▸ Target architectures include DeepLabV3+, U-Net, and SAM as segmentation models enabled reproducibly by this dataset for the first time.

Por qué importa

Why It Matters

  • Cada modelo de deep learning publicado para detección de erosión fue entrenado con datos privados y no reproducibles.
  • El estándar dominante, RUSLE, predice susceptibilidad, no presencia real, y sus predicciones se desvían de mediciones en campo por factores de 0,04× a 8×; solo el 41% de los estudios los valida con datos medidos.
  • La detección por deep learning de cárcavas, erosión en masa y erosión laminar requiere etiquetas confirmadas visualmente, no predicciones deterministas.
  • SoilSaveR es la primera infraestructura de datos que hace posible entrenar y comparar modelos de segmentación de erosión de forma abierta y reproducible, combinando 10 fuentes de datos distintas.
  • Every published deep learning model for erosion detection was trained on private, non-reproducible data.
  • The dominant standard, RUSLE, predicts susceptibility, not actual presence, and its predictions deviate from field measurements by factors of 0.04× to 8×; only 41% of studies validate against measured data.
  • Deep learning detection of gullies, mass wasting, and sheet erosion requires visually confirmed labels, not deterministic predictions.
  • SoilSaveR is the first data infrastructure that makes it possible to train and compare erosion segmentation models openly and reproducibly, by combining 10 different data sources.
